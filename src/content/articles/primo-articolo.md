Il Markdown è un linguaggio di markup leggero che ti permette di scrivere testo formattato usando un semplice editor di testo. 

## Vantaggi del Markdown

1. **Semplicità**: Non devi distogliere l'attenzione dal testo per formattarlo.
2. **Portabilità**: I file `.md` possono essere aperti da qualsiasi dispositivo o piattaforma.
3. **Integrazione**: Funziona perfettamente con generatori di siti statici e framework come React, Next.js e Vite.

Ecco un esempio di tabella che puoi usare:

| Feature | Supportata |
|---------|:---:|
| Grassetto | Sì |
| Tabelle | Sì |
| Liste | Sì |

```javascript
const message = "Ciao mondo!";
console.log(message);
```
